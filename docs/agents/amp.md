# Amp CLI - by Sourcegraph

## Installation

AgentHub's configured npm commands are:

```shell
npm install -g @ampcode/cli
npm update --quiet --no-fund -g @ampcode/cli
npm uninstall -g @ampcode/cli
```

Amp currently recommends its [direct installer](https://ampcode.com/docs/cli) on macOS, Linux,
and WSL. The npm package remains available as an alternative. The former `@sourcegraph/amp`
package was renamed to `@ampcode/cli`.

## Usage

Run `amp` in a project directory to start the interactive CLI. Use `amp --help` for the options
supported by the installed version. Amp's [CLI documentation](https://ampcode.com/docs/cli)
covers installation, updates, and current commands.
