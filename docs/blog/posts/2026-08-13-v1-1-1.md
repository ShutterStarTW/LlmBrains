# AgentHub 1.1.1 — Muse Code agent, Semgrep CLI

A small follow-up release: one new agent, one new companion tool.

<!-- more -->

## What's new

- **New agent — [Muse Code](https://developer.meta.com/ai/products/muse-code/)** by Meta.
  A terminal coding agent powered by the Muse Spark model family that coordinates multiple
  persistent subagents for repo-scale software engineering tasks. No native Windows build —
  runs under WSL2 on Windows.
- **New companion tool — [Semgrep CLI](https://semgrep.dev)** by Semgrep. A static analysis
  security scanner that finds bugs and vulnerabilities with lightweight, language-aware rules.
  Off by default; enable in Settings.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub)
or search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
