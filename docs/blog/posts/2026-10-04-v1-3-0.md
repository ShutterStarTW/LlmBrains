# AgentHub 1.3.0 — Skills tab and shared data across IDEs

Version 1.2.0 let you see which skills your agents use. Version 1.3.0 lets you manage them: share
one skill with several agents, keep the copies in sync, and undo a change. Nothing on disk changes
until you have reviewed a plan.

<!-- more -->

## Skills

The new **Skills** tab lists global or project skills. Search them, or use the **Filters** popup to
narrow by state, ownership and agent.

- **Share…** is one checklist of agents. Check an agent to share the skill with it, uncheck it to
  stop. A skill that exists for only one agent can be moved to the shared folder from the same
  button.
- **Resync / Repair** brings a managed copy back in line. **Stop Sharing** removes a managed link
  or copy after a backup.
- **Resolve Conflict…** shows a file-level summary and a JetBrains diff. Keep the shared version,
  the agent's version, or both.
- **Migrate duplicates…** and **Clean up redundant copies…** tidy identical copies in one reviewed
  batch.
- **Undo** and **Restore Backup…** show what they will change first, and still work after an IDE
  restart.

Every change is planned before it is applied and backs up whatever it replaces. The settings dialog
sets the Link or Copy mode, backups and plan review. **Manage existing skills** is off by default:
AgentHub then removes only the links and copies it created. When it is on, Stop Sharing can also
remove an existing link or an identical copy, always after a backup.

See the [Skills documentation](../../skills.md) for details.

## Shared data across IDEs

Skill ownership, history, settings and backups are now stored in **~/.agenthub**, shared by all
JetBrains IDEs under the same OS user. Data from the old per-IDE files is imported automatically and
the originals are left in place. A change made in one IDE shows up in the others when you return to
the window or refresh. Set **AGENTHUB_HOME** to use another folder.

## Tool window

- Projects, Agents and Skills now share one layout: search under the tabs, a header naming the open
  item, and one list/details divider.
- Sessions show the agent's title (or your first prompt), the prompt count and the time range, plus
  usage statistics where the agent records them. Only messages you typed are counted. **Resume**
  works for Claude Code, Codex CLI and OpenCode; **Transcript** opens the session file.
- The Environment tab also lists agent configuration files (Config), with warnings for
  approval-bypass or unrestricted sandbox modes. Credentials and raw file contents are never stored.
- Only agents whose CLI the latest detection found are shown. Detection now runs on every IDE start.
- Row menus open with **Shift+F10**, Environment filters show counts and a reset button, and
  Settings fields have accessible labels.

## Windows and WSL

The Skills tab works on the IDE host's files. While WSL mode is on, actions that change skills are
disabled, so AgentHub never writes to Windows folders while your agents read a WSL home.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub) or
search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
