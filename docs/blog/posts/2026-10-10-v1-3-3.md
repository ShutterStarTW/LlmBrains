# AgentHub 1.3.3 — Reliability fixes

A maintenance release after a full code review of 1.3.2.

<!-- more -->

## Skills

- When an atomic replace fails during sync, the original is restored. It is no longer deleted.

## Windows and WSL

- Detection, update and install results belong to the environment they were started in. Switching
  between Windows and a WSL distribution cannot apply a stale result.
- The tool window index is refreshed per environment, and outdated completions are dropped.
- Resume and Launch start in the session's own directory. If it is missing, a warning is shown instead
  of opening the IDE's directory.
- A hung WSL distribution lookup times out. Large output from background installs no longer blocks them.

## Updates

- Update checks validate the npm/pip report. A failed query shows `?`, never "up to date".
- **Update all** clears the outdated flag only for agents that were actually updated.
- Update commands with pipes or fallbacks run as written.

## Agents

- **Devin**, **ForgeCode** and **Junie CLI** install through npm. The old ForgeCode installer URL
  returned 404. ForgeCode is no longer hidden on Windows.
- Mistral Vibe updates no longer use `--upgrade-strategy eager`.
- Junie sessions beyond about 1,700 are no longer cut off.
- Session ids starting with `-` are refused by Resume.
- The one-time Kimi migration prompt was removed.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub) or
search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
