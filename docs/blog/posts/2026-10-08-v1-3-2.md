# AgentHub 1.3.2 — WSL in the tool window, tidier skill sharing

<!-- more -->

## WSL mode reaches the tool window

The tool window now follows **Run agents in: WSL**. It reads the agents' data from the distribution's home
directory (over the `\\wsl.localhost\<distro>` share): sessions, skills, MCP servers, instruction files and
configuration.

- **Projects** in the distro show their Linux path; Git remote and branch are read from the `.git` files.
- **Resume** and **Launch** start the agent inside the distro, in the project's directory.
- **Skill sync** (Share, Promote, Resync, Undo) works on the distro's skill folders and links with symlinks.
  Backups stay in the Windows `~/.agenthub` folder.

## One set of settings per environment

Windows (native) and each WSL distribution keep their own settings: enabled agents and companion tools,
detection results and update status. The table headings name the environment (for example
*AgentHub · WSL (Ubuntu)*), and the toolbar menu lists the selection of the active one.

**Check installed agents** / **Check installed tools** under each table ticks what the last detection found
and unticks the rest.

## Redundant skill copies

- A shared skill has a **Redundant links / copies** section above *Additional sources*: agents that read the
  shared folder directly but keep their own link or identical copy. Each entry has **Remove link** /
  **Remove copy**. The Agents tab marks the same agents and offers the same button.
- An agent that cannot read the shared folder gets **Remove copy** for an identical copy, which replaces it
  with a link to the shared skill. The button is not shown in Copy mode.
- **Clean up redundant copies…** covers both cases.
- An already shared skill no longer offers *Move to Shared*.

## Smaller changes

- Skill icons and the agent filter show the agents a folder belongs to. System skills are grouped by agent.
- Plandex was removed from the agent list.
- The links of Auggie, Cody CLI, Droid, Grok Build, Muse Code, OpenHands and Qodo were updated.
- Every `v*` tag builds a GitHub Release with the plugin ZIP.
