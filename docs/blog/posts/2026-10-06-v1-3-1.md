# AgentHub 1.3.1 — Seven more agents in the tool window, Resume for all

Version 1.3.0 let you manage skills. Version 1.3.1 widens what the tool window can see, and makes
every session it lists resumable.

<!-- more -->

## Seven more agents

The tool window now discovers **Kilo Code, Kimi Code, Oh My Pi, Junie CLI, Mistral Vibe, Freebuff and
MiMo Code**, next to the ten it already knew, for 17 in total. For each of them it reads the projects
and sessions, and shows the Skills, MCP servers, instruction files and configuration files that belong
to a project. Everything stays read-only; credentials and raw file contents are never stored.

Where an agent has a skill folder of its own, it is also a target of **Share…**. Freebuff has none, so it
reads the shared `.agents/skills` folder and the Claude-compatible `.claude/skills`.

## Resume for every agent

**Resume** reopens a session in its own agent. It used to work for Claude Code, Codex CLI and OpenCode;
it now works for all 17. Each command was checked against the installed CLI's `--help`, and a session id
that is not safe to put on a command line is refused rather than quoted.

## Installed agents show up before their first session

The Agents tab lists every installed agent, not only the ones that already have sessions. A freshly
installed agent appears at once, marked "No sessions yet". Its Projects and Sessions tabs are greyed out
until there is something to show, and its Environment tab already lists the agent's global skills, MCP
servers, instruction files and configuration.

## Quieter in the background

The tool window used to re-read and re-scan more than it needed to. AgentHub's own saves are no longer
mistaken for changes made by another IDE (which could trigger a full rescan on every click), unchanged
results are not written to disk again, the saved indexes are decoded once instead of on every redraw, and
checks for changes made elsewhere run at most every few seconds.

## Smaller changes


- Skill sync: the engine was reorganised, and symlinked skill folders are now walked.
- Claude `AGENTS.md` and `CLAUDE_CONFIG_DIR`, OpenCode `.opencode` and `OPENCODE_CONFIG(_DIR)`, and Qwen
  `.qwen/rules` are discovered.
- An instruction file that an agent does not apply (for example `AGENTS.md` next to a `CLAUDE.md` in
  Claude Code) is still listed, with a note saying why.
- Same-named Antigravity MCP servers from different files are listed separately.

The [discovery paths](../../environment-paths.md) page lists the sources and the resume command of every
agent.
