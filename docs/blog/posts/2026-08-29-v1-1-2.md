# AgentHub 1.1.2 — Oh My Pi agent, "Update all agents" fix

One new agent, one bugfix release.

<!-- more -->

## What's new

- **New agent — [Oh My Pi](https://omp.sh)** by can1357. A coding-first fork of
  [Pi](https://pi.dev) with LSP/DAP integration, browser & desktop tools,
  subagents, sessions, memory backends, 60+ providers and ACP support.
  Thanks to community contributor [@ralfsqual](https://github.com/ralfsqual)
  for the [pull request](https://github.com/ShutterStarTW/LlmBrains/pull/1).

## What's fixed

- **"Update all agents"** used to run every installed agent's update command
  (`npm update`, `pip install --upgrade`, etc.) on every click, regardless of
  whether a newer version was actually available. It now only touches agents
  that the last "Check for updates" run (or the background check) flagged as
  outdated — matching how the per-agent Update button in Settings already
  behaved. If nothing is known to be outdated, it shows a notice instead of
  silently updating everything.
- **Windows: false "up to date" reports fixed.** The PowerShell helper script
  never checked the exit code of a version-check command, so a command that
  failed outright (e.g. a missing runtime dependency) had its error text
  mistaken for a version string and reported as a green "up to date" — found
  while testing the new Oh My Pi agent.
