# AgentHub 1.1.0 — WSL mode & Pi agent, 9 companion tools

A new WSL execution mode on Windows, a new coding agent, and a big batch of companion tools.

<!-- more -->

## WSL mode (Windows)

AgentHub can now run agents either **natively** or inside a **WSL distribution** on Windows.
Enable it in **Settings/Preferences > Tools > AgentHub > Behavior**, under *"Run agents in:"*.

- Every command — launch, detection, install/update/remove — runs inside the chosen distro.
- Detection is **distro-native**: it ignores Windows-side binaries exposed through WSL interop,
  so an agent only installed on the Windows side won't show up as "installed" inside the distro.
- The Linux/WSL-only agents **ForgeCode**, **LeanCTL**, **Plandex** and **Command Code** — hidden
  on native Windows because they have no native build — become available.
- A missing `pip`/`npm` in the distro now gets a friendly install hint instead of a silent failure.

See [WSL Mode](../../wsl-mode.md) in the docs for the full rundown.

## What's new

- **New agent — [Pi](https://pi.dev)** by Mario Zechner. A minimalist, multi-provider
  terminal coding agent harness (Anthropic, OpenAI, Google and more), extensible via
  Skills and Pi packages.
- **Seven new companion tools:**
    - **Claude Code Router** &mdash; routes Claude Code requests to other providers/models
    - **Claude-Code-Usage-Monitor** &mdash; live, predictive token & cost dashboard
    - **code2prompt** &mdash; codebase to LLM prompt with Handlebars templating
    - **CodeGrab** &mdash; interactive TUI repo-context packer with secret redaction
    - **CodeRabbit CLI** &mdash; AI code reviews directly in the terminal (macOS/Linux only for now)
    - **LiteLLM** &mdash; self-hosted multi-provider LLM gateway with cost tracking
    - **Tokscale** &mdash; TUI token & cost dashboard with a contribution graph
