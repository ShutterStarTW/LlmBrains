# AgentHub 1.2.0 — Projects & Environment Discovery tool window

The biggest release yet: a new **AgentHub tool window** turns the plugin from a launcher into a
read-only, local-first inspector for the projects and environment (skills, MCP servers,
instructions) your coding agents already know about. Nothing leaves your machine, and no agent
file is ever modified.

<!-- more -->

## Projects & Agents

Open the **AgentHub** tool window on the right side of the IDE to browse every project you've
used with Antigravity, Claude Code, Cline, Codex CLI, GitHub Copilot CLI, Cursor CLI, Grok Build,
Kiro CLI, OpenCode, or Qwen Code.

- **Projects** lists repositories by recent activity, with participating agents and session totals.
- **Agents** flips the view around: every discovered agent and all the projects used with it.
- **Cross-agent project merging** normalizes local paths and Git remotes (SSH/HTTPS), so sessions
  reported by multiple agents for the same repository show up as a single project instead of
  duplicates.
- Select a project to see its path, Git remote, branch, per-agent activity, and session counts.
- **Open in IDE** recommends an installed JetBrains product based on project-root markers
  (Gradle, Composer, npm, Python, Go, .NET, Android, …) and opens it in the current IDE or as a
  separate process.
- **Launch** starts any participating agent with the project directory as the working directory,
  reusing the same terminal launch path as the toolbar.
- Search filters both views, and refreshing rescans local metadata off the UI thread.

## Environment discovery

Every project (and every agent) also gets an **Environment** tab that discovers and normalizes
**Skills**, **MCP servers**, and **instruction files** (`AGENTS.md`, `CLAUDE.md`,
`.cursor/rules`, …) across the same 10 agents.

- **Duplicate & conflict detection** flags skills or MCP servers that exist under multiple agents
  and shows whether the copies are identical or have diverged.
- **Secret-safe by construction** — MCP commands, arguments, URLs, headers, and environment
  *values* are never rendered; only variable *names* and normalized metadata make it into the UI
  or the persistent cache.
- Warnings from a failing provider (a malformed config file, an unreadable session) show up right
  in the comparison table instead of silently disappearing.

## Built to stay out of your way

- The persistent index survives IDE restarts, so reopening the tool window shows cached results
  immediately while a fresh scan runs in the background.
- Discovery isolates malformed records per-provider — one broken config file doesn't take down
  the rest of the scan — and is covered by a 10,000-session performance regression test.
- Everything runs off the UI thread and is entirely read-only: nothing is written back to an
  agent's own files or databases, and no command or script is ever executed from what's
  discovered.

## Get it

Install from the [JetBrains Marketplace](https://plugins.jetbrains.com/plugin/32310-agenthub)
or search for **AgentHub** in **Settings/Preferences > Plugins > Marketplace**.
