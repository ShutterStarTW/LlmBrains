- `1.1.2`: Added the **Oh My Pi** CLI agent (can1357) &mdash; coding-first fork of Pi with LSP/DAP integration, browser & desktop tools, subagents and 60+ providers. Fixed **"Update all agents"** running every installed agent's update command regardless of whether a newer version was actually available &mdash; it now only touches agents flagged outdated by the last "Check for updates" run (matching the per-agent Update button in Settings), and shows a notice instead of doing nothing silently when no updates are known. Fixed (Windows): a failing version-check command was silently reported as "up to date" instead of a warning, because the PowerShell helper never checked the process exit code.
- `1.1.1`: Added the **Muse Code** CLI agent (Meta) &mdash; terminal coding agent for multi-agent, repo-scale software engineering tasks, powered by the Muse Spark model family. (WSL-only on Windows; the installer has no native Windows build.) New companion tool &mdash; **Semgrep CLI** &mdash; static analysis security scanner.
- `1.1.0`: New **WSL mode** (Windows): Settings &rarr; Behavior &rarr; "Run agents in:" lets every agent/companion tool run inside a WSL distribution instead of natively &mdash; detection is distro-native, and the Linux/WSL-only agents ForgeCode, LeanCTL, Plandex and Command Code become available. New agent &mdash; **Pi** (Mario Zechner) &mdash; a minimalist, multi-provider terminal coding agent. Seven new companion tools &mdash; **Claude Code Router**, **Claude-Code-Usage-Monitor**, **code2prompt**, **CodeGrab**, **CodeRabbit CLI**, **LiteLLM** and **Tokscale**. (CodeRabbit CLI is hidden on Windows.)
- `1.0.0`: First stable release. New **Companion Tools** section &mdash; optional CLI utilities that work alongside the agents (usage tracking, context packing, skills): **ccusage**, **Repomix**, **Skills** and **TokenTracker**. Off by default; enable in Settings. Companion tools reuse the agent install/detect/update/launch flow but appear in their own section. (Command Code is hidden on Windows: its launch command `cmd` collides with the built-in Windows command.) Seven new agents &mdash; **CodeBuddy** (Tencent), **Command Code**, **Devin** (Cognition), **iFlow CLI**, **Junie CLI** (JetBrains), **Kode** and **OpenClaw**.
- `0.9.1`: Added the **Freebuff** CLI agent (Codebuff). Toolbar install of a not-installed agent now honors the "Run operations in background" setting, and a background-installed agent launches automatically once ready. Lowered the minimum platform to JetBrains IDE 2024.1+ (build 241+).
- `0.9.0`: Initial release as **AgentHub**. 30 built-in CLI coding agents with auto-detection and per-agent favicon icons; one-click launch from the toolbar (not-installed agents prompt to install with confirmation); auto-detect on first install and after each plugin update, with results persisted across IDE restarts; background update-availability check on IDE startup; install/update/remove directly from the Settings panel with background result polling; custom agent support (name, command, URL); cross-platform (macOS, Linux, Windows PowerShell helper script). Requires JetBrains IDE 2025.1+ (build 251+).
